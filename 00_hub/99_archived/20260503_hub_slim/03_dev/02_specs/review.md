# Code Review 规范

## 当前状态

当前为单人开发，Code Review 由 AI 助手自检替代。

## 自检清单

- [ ] `./star build` 零错误零警告（允许无害 warning）
- [ ] `bash tools/check_schema_generated.sh` 通过
- [ ] 单进程端到端测试通过
- [ ] spec 文档已同步更新
- [ ] 无硬编码（数值/字符串/枚举）
- [ ] 命名符合编码规范
- [ ] 新代码遵循 header-only 约束

## Review 聚焦点

1. **正确性**：逻辑是否正确、边界条件是否处理
2. **一致性**：与现有代码风格和架构是否一致
3. **安全性**：是否有内存泄漏、竞态条件、未定义行为
4. **可维护性**：命名是否清晰、结构是否合理
5. **Spec 对齐**：是否与对应 spec 文档的契约一致
