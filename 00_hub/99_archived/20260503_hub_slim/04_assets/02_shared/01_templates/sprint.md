# Sprint 模板

```markdown
# Sprint [名称/编号]

## 概览

| 属性 | 值 |
|------|-----|
| 周期 | YYYY-MM-DD ~ YYYY-MM-DD |
| 目标 | 一句话描述 sprint 目标 |
| 状态 | planning / active / completed |

## 任务列表

| ID | 标题 | 优先级 | 状态 | 指派 | 验收 |
|----|------|--------|------|------|------|
| | | | | | |

## Sprint Goal

（本次 sprint 要达成的具体目标）

## 阻塞项

| 任务 | 阻塞原因 | 解决方案 | 预计解除时间 |
|------|----------|----------|--------------|

## 复盘

（sprint 结束后填写：什么做得好、什么可以改进）
```
